# 可归责现实跃迁（ART）

**一个用于研究自主主体跨信任边界改变现实的可证伪理论框架。**

ART 是 **认知涌现（Cognitive Emergence）** 的开放研究计划。

它追问一个基础问题：

> **当自主主体开始跨越信任边界改变现实后，哪些结构无论如何命名、如何实现，都无法被删除？**

ART 不预设某个协议、产品、法律理论或“统一世界模型”天然正确。它从攻击开始：删除结构、替换结构、禁止显式表达，再观察系统为了继续运行是否被迫重建语义等价物。

## 当前工作假设

对于具有后果、跨信任边界的自主行动，目前最难删除的三个候选结构是：

1. **Target（目标）**——希望发生什么变化，以及什么条件才算完成；
2. **Bounded Authority（受限权限）**——谁可以使变化发生，权限的范围、约束和有效期是什么；
3. **Verification（验证）**——一个被声称的变化如何成为有证据支持、可被接受的状态。

随着自主性、自由裁量、委托深度和制度后果增加，以下结构可能被迫进一步显性化：**Judgment、Delegation、Termination、Causal Attribution、Responsibility、Settlement**。

这些都是**研究假设**，不是已经成立的自然原语。

## 研究纪律

ART 只应该在经得住攻击时继续存在。主要测试包括：

- **删除测试**：删除候选结构后，系统还能否完成目标？
- **替代测试**：是否存在更简单的既有概念可以无损替代？
- **隐藏重建测试**：禁止显式表达后，同一语义是否会重新出现在策略、代码、日志、合同或人工流程中？
- **跨域测试**：完全不同领域是否重复出现同构结构？
- **独立收敛测试**：不提供 ART 术语时，独立设计者面对相同约束是否仍会推导出同构结构？

失败的假设应被修改或删除，而不是被保护。

## 与 TSTO / JEP 的关系

ART 是**理论层**，与具体工程工件分离。

- **TSTO** 用机器可验证对象表达“什么目标状态变化才算完成”；
- **JEP** 探索 Judgment、Delegation、Termination、Verification 等事件的可互操作表达。

ART 不依赖 TSTO/JEP 必须正确；TSTO/JEP 的存在也不能证明 ART。三层必须分别接受反证。

## 当前优先级

1. 攻击 Target / Bounded Authority / Verification 的不可删除性；
2. 攻击 J/D/T/V 是否真的是最小事件基底；
3. 建立跨领域反证语料库；
4. 维护带时间戳的预测账本；
5. 主动邀请更简单的替代理论和失败案例。
