# Papers and Archived Releases

This directory is reserved for stable research-paper snapshots and publication artifacts related to ART.

## Publication discipline

A paper snapshot should identify:

- title;
- version;
- publication date;
- publisher/author attribution;
- review status;
- DOI or archival identifier when available;
- commit or tag corresponding to the text.

Published snapshots should not be silently rewritten. Corrections should produce a new version or an explicit erratum.
